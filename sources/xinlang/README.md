# 新浪资源

Rex / ForwardWidgets 独立 VOD 模块，仅保留直接 M3U8 线路。

## 导入

```text
https://raw.githubusercontent.com/ukonic/Rex-VOD-Modules/main/sources/xinlang/Rex-Xinlang-VOD.js
```

## 功能

- 新浪资源最近更新
- 新浪电影、剧集、综艺、动漫、短剧
- 搜索新浪资源
- 加载新浪播放源

资源站登记名：新浪资源

接口：`http://api.xinlangapi.com/xinlangapi.php/provide/vod/`
